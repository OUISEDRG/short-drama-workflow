# 短剧工作流入口（按任务加载）

仅在用户要求短剧制作、剧梦操作或该工作流维护时使用以下路由。其他任务无需加载。
本机新项目的公共工作流默认位置：`{{WORKFLOW_ROOT}}`。
身份：`jumeng.short-drama.workflow` / `jumeng.short-drama.core-skills`。
安装时定位器 `tools/workflow_paths.py` SHA-256：`{{LOCATOR_SHA256}}`。

1. 先明确当前短剧目录及用户授权范围，读该目录 AGENTS.md、项目启动说明.md、项目参数.json、制作台账.json。剧本、主语言、资产名称、平台项目和进度只取本剧事实；公共母版不保存单剧数据。
2. 已有项目以自己的工作流绑定.json、工作流版本锁.json和项目入口定位已接受版本。核对固定清单身份、定位器及依赖哈希后，运行定位器 doctor --project 检查。锁差异或缺绑定须报告并走具体项目迁移；不得回退到本机默认版本继续生产，不自动刷新锁。
3. 新建项目或公共维护使用上述默认位置。先只读清单和安装定位器哈希，身份一致后运行 doctor --json，读取工作流规则索引.md；新剧用现有 tools/init_project.py，在用户指定父目录初始化，不复制六个 Skill。目录搬动后从可信发布包重新安装入口；找不到时定位缺失，不扫描整盘猜测。
4. 按资源 ID 解析并读取任务所需文件。剧梦操作必须读取 skill.production 和 skill.adapter；剧本预拆解用 skill.prebreakdown，导演/表演用 skill.director / skill.acting，提示词编译用 skill.compiler。资源 ID 由定位器 resolve 解析，不是 Codex 原生技能名。操作浏览器时再加载当前可用的浏览器/计算机操作技能，按当前工具接口执行。
5. 按当前会话已有授权继续，不重复索要已经给出的生成许可；“先不要生成”立即限制为准备模式。真实引用、人物附带音频、保存回读、提交回查和成片验收按对应公共 Skill 执行。历史复盘只作证据，旧语种、旧时长和旧后期裁决不覆盖当前项目要求。
6. 维护公共库先读 maintenance/README.md。本机入口仅负责路由；实际操作经验只维护公共 Skill。入口安装不修改真实项目或授予剧梦登录、上传、生成、积分权限。

# 短剧工作流 3.5.1 · 可搬迁版

本次将尚未推送的 3 秒镜头规则、检查器补修和跨电脑安装入口一起发布。创作规则为 3.5.1，定位基础设施合同仍为 1.1.1；本次发布由 Git 标签与归档摘要单独标识。

## 更新内容

- **单镜上限 3 秒**：每个真实连续镜头满足 `0 < 时长 ≤ 3.000 秒`。总段长、SRT 与对白不会因拆镜被截短，跨镜对白仅发声一次。清单与最终提示词检查器分别检查镜头数量和时长。
- **检查器补修**：兼容第三镜文字延续的正式排版示例；正文镜头数和清单不一致时返回结构化错误，并继续检查可检查的镜头，避免异常退出。
- **跨电脑入口**：新增 `maintenance/portable.py` 和 PowerShell 包装。安装器按当前机器路径生成 Codex 全局入口，保留原有规则、安装前备份并支持受保护回退；重复安装不重复写入。六个公共 Skill 保持一份。
- **剧梦经验继承**：资产适配与制作总控 Skill 增加真实引用芯片、完整资产名、人物附带音频、重新编辑后的再绑定、保存回读、提交队列核对与分阶段验收规范。具体剧目的语言、人物和画面要求仍取该项目自己的资料。
- **搬迁诊断**：可只读检查已有项目的工作流绑定、内容锁和项目参数里的绝对路径；发现差异后由项目迁移流程审查，不自动改写项目。

## 在另一台电脑使用

1. 解压本次发布 ZIP，保留其内部目录结构；另行复制目标短剧的完整项目目录。
2. 准备 Python 3.10 及以上版本，在工作流目录执行 `python -B maintenance/portable.py install`，再执行 `python -B maintenance/portable.py check`。
3. 已有剧再执行 `python -B maintenance/portable.py check --project '新位置的项目目录'`，审查绑定与路径结果。
4. 在项目目录新开 Codex 对话，先做一次仅填提示词和引用、不点击生成的剧梦现场核验。

详细说明见 [`maintenance/搬迁与安装.md`](搬迁与安装.md)。

## 验证与边界

- 离线完整回归 **106/106 通过**；两个修改的 Skill 格式检查通过。
- 临时副本改动两个外层目录名后，项目初始化、绑定、内容锁和单段检查通过。
- 本机全局入口安装、自检及重复安装验证通过。第二台实体电脑的 Codex 登录、剧梦页面与人物音频状态需到该机现场核验。
- 未迁移任何真实短剧项目，未刷新其内容锁；静态检查通过不表示视频画面或音轨已验收。

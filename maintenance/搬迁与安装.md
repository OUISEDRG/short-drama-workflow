# 换一台电脑继续使用

## 要带走什么

复制或解压完整公共工作流目录，保留内部目录结构。外层公共目录和六 Skill 所在外层目录可以改名；工具靠 manifest 身份识别。各部剧的剧本、素材、参数、台账、工作流绑定和内容锁需随各自项目完整复制。公共包不包含剧本、浏览器登录、账号、积分或视频。

## 新电脑安装

1. 安装并登录 Codex，准备 Python 3.10 或以上版本。
2. 把公共包放在希望长期保存的位置，打开该目录的 PowerShell。
3. 执行 `python -B maintenance/portable.py install`，再执行 `python -B maintenance/portable.py check`。
4. 新开 Codex 对话，以目标短剧目录为工作目录，要求先读取该项目入口、绑定和台账，再加载绑定的公共 Skill。核对报告的项目、公共版本和当前授权范围。

也可运行 `& '.\maintenance\安装工作流.ps1' -Mode install`。脚本会寻找 Python，不自动改变系统执行策略或安装软件。PowerShell 禁止脚本时，使用上面的 Python 命令。

安装根据本机 `CODEX_HOME`（若设置）或当前用户的 `.codex` 定位 AGENTS.md，在受管块中写入实际公共目录与定位工具哈希；不会复制六份 Skill。原有块外规则逐字节保留，首次修改前自动备份。相同安装重复执行不会重复写入。非空 AGENTS.override.md 会遮蔽入口，安装因此停止并说明原因，需人工审查该覆盖规则。安装路径变化后从新位置重新运行 install。

全局入口负责按需读取公共 Skill；它不代表六个 Skill 已出现在应用的 Skill 选择器，也不会让已打开的对话自动重新加载规则。必须新开对话做一次实际入口确认。

## 已有项目的搬迁检查

执行 `python -B maintenance/portable.py check --project '新位置的项目目录'`。此命令只读：从项目自身绑定查找公共目录并检查内容锁，诊断项目参数中的绝对路径。可搬迁候选路径仅供审查，不会写回。

覆盖范围是项目参数中的绝对路径；文档、外部脚本、软件工程内部和所有相对路径不属于该扫描的完整性承诺。项目 root/common_root 作为历史提示单列，其他旧绝对路径即使仍存在也需人工核对是否指向旧副本。浏览器连接、平台登录和画面/声音仍需本机现场检查。

版本不符或绑定找不到时停止该项目生产，依据根 README 的显式单项目迁移流程处理；不能为了让检查通过直接重写绑定或刷新锁。安装公共入口不自动升级已有项目。

## 备份与回退

安装输出 entry 和 backup 的实际路径。需要撤销时执行 `python -B maintenance/portable.py restore --backup '安装输出的备份文件'`。如使用自定义配置目录，所有命令一致追加 `--codex-home '目录'`。

只有当前入口仍等于那次安装结果才会回退；安装后手工修改过的规则会被保护，需人工合并。首次安装前没有 AGENTS.md 时，回退移除本次创建的文件。备份中保留原始字节，不携带认证文件。

## 验收边界

自动测试覆盖临时副本改路径、安装/回退、项目绑定和内容锁、参数路径诊断及保护原规则。它不证明第二台实体电脑已经登录、不证明应用已加载 Skill，也不证明剧梦页面布局或视频效果不变。每台新电脑首次使用须做一次只填提示词和引用、禁止生成的现场验收，检查真实芯片和人物附带音频。

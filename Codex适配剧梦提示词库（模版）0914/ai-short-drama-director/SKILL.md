# AI 短剧导演

## 使用边界

本 Skill 是 L3 导演决策层。它回答“这场戏为什么这样拍、观众应看见什么、镜头怎样证明变化”，不替代剧本事实整理、模型 Prompt 编译或剧梦平台执行。

- 剧本事实、对白、人物知识、空间和素材候选由 `../screenplay-prebreakdown-analysis/SKILL.md` 提供。
- 表演语言需要细化时，读取 `../cinematic-acting-execution-library/SKILL.md`。
- 动态拆段、时间预算、风险、控制深度和最终视频 Prompt 交给 `../sd25-video-prompt-compiler/SKILL.md`。
- 素材引用、页面配置、生成授权和平台状态交给剧梦适配与制作总控。

## 必读规范

执行导演分析、分镜设计、连续性审查或 Take 导演验收前，完整读取 [AI短剧导演核心规范_v3.4.md](references/AI短剧导演核心规范_v3.4.md)。该文件是本 Skill 的唯一 L3 详细规范；不要在入口文件重复维护一份简化版规则。

## 输入门禁

确认以下信息，缺失项只阻塞真正受影响的范围：

- 当前任务范围、交付形式和临时要求；
- 权威剧本、对白、VO/OS 及其声音权限；
- L1 项目身份、画幅、语言、角色和资产约束；
- 当前段开始状态、剧本要求的结束状态；
- 上一段已接受成片的 Sequence Canon；
- 来源冲突、未知项和必须保留的信息。

未经明确授权，不改写权威剧情、对白、人物身份、结局或项目硬规则。

## 导演工作流

遵守当前用户/SRT时间来源与≤5秒单镜上限；长对白跨真实切点保留完整声音。旁白只转对应画面，所有输出人声/文字均主语言；不可为满足时长新增剧情或省略关键证据。

1. 锁定事实、开始状态、结束状态以及观众与角色各自知道的信息。
2. 确定当前戏剧任务、关系或主动权变化，并判断戏剧价值；戏剧价值不得代替生成风险判断。
3. 选择能够证明变化的最小充分视觉证据，明确刺激、反应、动作结果和保持项。
4. 根据空间、轴线、视线、出入场、持物和多人关系设计镜头功能；镜头数量由内容决定。
5. 需要表演细化时只选当前镜头可见且有因果作用的信号，不堆叠装饰动作。
6. 给出可交给 L2 的镜头账本和连续性条件，不提前写死平台参数或虚构素材引用。
7. 审核成片时依据实际视听证据判定接受、后期修复、局部编辑、重新采样或重写方案；只有接受的结果进入 Sequence Canon。

## 输出合同

按任务需要输出以下最小集合，不为形式补空表：

- 权威事实与开始/结束状态；
- 戏剧任务、知识差和关系变化；
- 戏剧价值及其依据；
- 主要视觉证据与必要支持信号；
- 镜头功能、构图/机位意图和镜间连接；
- 空间、视线、动作、持物与声音连续性；
- 交给 Prompt Compiler 的硬约束、可调项和未知项；
- 成片审查时的实际证据、Take 判定与 Canon 更新项。

导演结果必须能由画面或声音验证；心理解释、氛围形容和镜头术语都不能替代可观察证据。

# 视频模型工作流配置｜SD2.5 v3.4

版本：v3.4｜状态：当前执行版｜日期：2026-09-11

定位：承接《AI短剧导演核心规范 v3.4》，把导演决定编译成可直接提交的视频提示词。保留自然语言，固定信息职责；不以长表单代替镜头设计。

# 0. 默认策略

先理解戏、确定观看重点，再写提示词。每次任务执行：**剧本事实 → 戏剧任务与起止状态 → 观众/角色知识 → 节拍和关系 → 空间/连续性 → 价值与风险 → Reference Authority → 镜头设计 → Video Prompt Compiler → 验收**。

用户只要求“直接给提示词”时，隐藏分析展示，不跳过这些步骤。所有完整视频提示词均按第 7 章组织；简单段落可以压缩模块标题，不能把关键镜头决策留给模型猜测。

当前用户的默认声音/成片偏好：**无 BGM、保留环境声、不烧录字幕、不出现 Logo、不擅增对白或 VO**。每次独立提交在全局区明示；其他项目若有不同授权，以当前 L0/L1 为准。画幅、分辨率、角色与场景从当前项目读取，不沿用学习素材参数。

# 1. 文件定位与能力边界

本文件负责当前模型工作方法、编译结构、句法、拆段和辅助控制；导演通用原则与文生图十维在核心规范，作品身份在项目配置。L0 当前任务优先，L1 项目身份不得因 L2 模型便利性被静默改写。

## 1.1 官方能力层与可用界面

2026-09-10 核对的官方发布材料说明：支持多轮延长、多参考输入、多镜头叙事、时间戳控制及定向编辑，并包含白模、运动参考、视角与绿幕等能力。具体时长和参考输入上限以当前入口的实时界面为准；复杂运动和多主体交互仍需谨慎验收。

来源：[ByteDance Seed｜Introducing Seedance 2.5，2026-07-31](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)。

上述是官方模型能力说明，不保证用户当前入口已开放全部功能。开工时以实际界面的时长、参考输入、编辑和输出选项为准；没有入口就采用拆段或后期方案，不虚构 API、参数或工具支持。时间戳是执行目标，不代表生成必然逐帧精准；实际输出和后期规格分开记录。

## 1.2 内部生产规则

- 第 2—11 章属于本工作流约定与生产判断，不冒充官方保证。
- 片长由对白、顺序动作、反应、空间变化和风险决定。
- 不为普通片段强制故事板；必要的导演分析、取景选择和动作承接仍必须完成。
- A/A+/B 仅表示戏剧价值。生成风险另记低/中/高；控制深度另记 R0/R1/R2。

# 2. 默认工作流与交付分层

| 阶段 | 内部产物 | 进入模型提示的内容 |
|---|---|---|
| 事实与导演分析 | 原文台词/VO清单、开始/结束、知识差、戏剧任务、A/A+/B、Lite | 仅经转换后的画面与声音，不复制心理解释 |
| 节拍与镜头 | 镜头账本：功能、观看对象、证据、触发、结束状态 | 景别、机位、动作、镜头响应、切换 |
| 风险控制 | 低/中/高风险、R0/R1/R2、辅助素材计划 | 真正需要的起止状态与局部限制 |
| 参考裁决 | 每一维唯一最高权威；真实已绑定素材列表 | 简明职责，不用虚构 @编号 |
| 编译 | 第 7 章编译步骤与自检 | 全局、参考、起点、时间轴、必要约束 |
| 验收与反馈 | 实际切点、因果、结尾、声画、Take 判定 | 修正时仅重编失败变量；接受后更新 Canon |

内部原文清单是权威文本的单一来源。最终提交不另附一次完整对白总表：只在发生的时间段出现一次，避免模型重复发声。用户另要分镜表时可以展示，但不能将两套重复时间轴一起提交。

# 3. 动态拆段与时间预算

## 3.1 留在同一请求或拆开

同一场景、同一核心任务、身份和关系连续、动作容量合理时可保留一段，多镜头不自动要求多次生成。出现地点/时间改变、多人复杂交叉、连续接触、精确道具、严格首尾依赖或同类失败时，优先拆段或强化真正风险项。

拆段边界保留可接的状态：人物位置、视线、持物、动作是否已完成。不要把关键接触过程切掉，再让下一段凭空处于结果。

## 3.2 时间预算先于时间码

1. 把权威对白/VO按原顺序排入，使用实际试读、配音或已有音轨估时；没有音轨时记录估计，不宣称已验证口播时长。
2. 为关键顺序动作与认知反应留时间。可与对白自然并行的简单动作不重复相加；必须先完成才能发生的节点逐项计入。
3. 为结尾的新状态预留可读余波，再分配铺垫和过渡。禁止将两句台词、遮挡、消失、寻找及新姿态全部塞进最后几秒。
4. 若超载，删低价值停留或移动、调整镜头覆盖、拆请求。不可擅删原文、加速到不可理解或省掉关键因果。

## 3.3 三种时间单位

- 生成片段：一次提交的总时长。
- 镜头：一次持续取景，镜号变化必须有明确切换；镜头内可变焦点或构图。
- 节拍：一次信息、动作、情绪或关系变化，可能在同一镜头内发生。

不要把时间段数量当镜头数。连续镜头使用“镜头 1／节拍 a、b、c”；多镜头使用“镜头 1、2、3”并写明硬切或其他连接。

# 4. 戏剧价值、风险与控制深度

| 戏剧价值 | 导演任务 | 最低覆盖 |
|---|---|---|
| A | 普通叙事 | 功能明确、动作可接、信息不重复 |
| A+ | 重要情绪/关系/信息 | Lite、变化证据、必要反应 |
| B | 核心爽点/反转/真相/收束 | Lite、预期与释放、受影响者、关系结果及余波；按剧情选择 |

| 生成风险 | 常见条件 | 控制深度 |
|---|---|---|
| 低 | 单人反应、清楚站位、简单独立动作 | R0：短而完整的执行描述 |
| 中 | 双人接触、短距移动、进出、遮挡、严格视线 | R1：补具体起止、路径、接触点、持物或局部约束 |
| 高 | 复杂接触、多人交叉、精确小物、严格转换、重复失败 | R2：按根因选关键帧/分镜/运动参考/拆段/编辑 |

示例：真相揭示可能是 B＋低风险＋R0；普通递物可能是 A＋中风险＋R1。不能因为低风险而省掉 B 段落导演设计，也不能因为 B 就自动做大量运镜。

# 5. 辅助工具选择

| 手段 | 适用问题 | 使用边界 |
|---|---|---|
| 直接文本视频 | 空间、动作、视点可以简明说明 | 不省略关键切点和关系 |
| 首帧/尾帧 | 起始或结束构图必须锁定 | 尾帧不得提前占用起始状态；不替代中间因果 |
| 关键帧 | 接触前/中/后或关键姿态难稳定 | 关键帧不必成为独立镜头 |
| 真人分镜/运动参考 | 重心、路径、人体接触难以文字说明 | 只取所需维度，不继承无关身份、服装和声音 |
| 故事板 | 空间关系、越轴、进出或镜头序列反复失败 | 不作为全部任务门禁 |
| Clay Render | 复杂空间与机位预演 | 以当前入口支持为前提 |
| 定向编辑 | 正确片段内某时段或局部失败 | 保护正确脸、站位、动作与光线 |
| 外部剪辑/后期 | 声画跨镜、精确文字、局部标识、复杂转场 | 修复后重验；不把尚未修复内容判通过 |

# 6. 参考素材职责与 Reference Authority

每个控制维度只保留一个最高权威来源；一个来源可控制多维。先裁决再编译，不把冲突交模型自行解决。

| 维度 | 优先来源 | 排除串扰 |
|---|---|---|
| 面部身份、发型、年龄感 | 已锁定角色身份资产 | 其他图或运动视频的人脸不能覆盖 |
| 服装与体态资产 | 已锁定全身角色资产 | 不覆盖最高面部权威；款式与颜色不在执行文字复述 |
| 场景结构、出入口、固定光源 | 权威场景图 | 偶然人物不成为身份来源 |
| 起始站位、姿态、视线、持物 | 已接受上一段尾帧/Canon或明确首帧 | 不继承被拒绝错误，不恢复已结束动作 |
| 结束姿态 | 当前任务终点与有效尾帧 | 不允许提前进入终点 |
| 道具归属 | 剧本、项目状态及已接受 Canon | 不因参考偶然持物而换人、换手 |
| 动作路径、重心、节拍 | 指定运动参考 | 不自动继承其人物、背景、字幕、Logo、音乐 |
| 摄影路径 | 指定机位参考或导演设计 | 不被无关运动参考覆盖 |
| 声音身份 | 已授权声音资产 | 不继承无关原声或新增说话人 |

执行提示使用当前平台真实绑定的素材名称/编号。只有实际可用的素材才写 @引用；“图1”“上一段”不是自动存在的资产。缺少关键资产时查找当前已提供材料；仍缺则列出缺口，不能把占位符版本称为可直接提交。用户授权纯文本试验时可不用参考，但不得宣称匹配既有角色资产。

“参考承载已有状态，文字描述本段变化”不意味着省去关键站位：参考模糊、裁切或高风险时，最小补写方向、视线和接触前后。正式名称用于执行主体；角色描述中不写服装款式与颜色。身份、服装等绑定职责可以写，不能夹带外观重定义。

# 7. Video Prompt Compiler｜固定编译规范

## 7.1 输入合同

输入包括：权威片段及上下文、原文对白/VO清单、项目硬规则、正式角色名、实际可用参考、开始/结束状态、已接受 Canon、戏剧价值与风险、节拍和镜头设计、当前模型入口限制。

缺口分两类：非关键未知如无依据的天气不强填；会改变身份、剧情、台词、必要信息或空间结果的缺口必须先解决。不得为填模板编造剧本、角色图或参数。

## 7.2 编译步骤

1. **锁文本**：对白/VO用内部唯一清单登记“顺序、发声者、类型、原文、接收者”，生成画面不得改写它。
2. **锁状态**：读取 Canon，明确本段起点、允许改变和必须留下的结果。
3. **定任务**：选 A/A+/B 与 Lite；明确观众知识、角色知识和最重要的变化。
4. **找证据**：导演意图转为视觉行为，给行为选能看清的部位、道具或人物距离。
5. **成镜头**：视觉行为转为景别、机位、焦点、主动作和镜头响应；每镜有功能，连接有原因。
6. **降风险**：独立评风险和 R 深度；省略无价值路程，不省略选择、接触或信息释放的必要证据。
7. **分时间**：按第 3 章预算；对白、停顿、顺序动作及结尾状态都能容纳。
8. **分权限**：为各维选唯一最高参考，删除素材串扰和虚构引用。
9. **写执行稿**：按第 7.3—7.6 节序列化；导演意图 → 视觉行为 → 镜头语言 → 模型执行语言，不能把内部分析原样输出。
10. **去重和预检**：按第 7.7、7.9 节检查；输出一个完整执行稿。若尚缺关键材料，准确标记未就绪，不冒充成片或已验证生成。

## 7.3 完整提示词的 Prompt Architecture

使用以下五个模块，保持此信息顺序。短段落可压缩标题，但语义职责不省略。

| 模块 | 放什么 | 为什么在这里 |
|---|---|---|
| ① 生成约定 | 总时长、当前画幅、具体质感/光线目标、镜头形式；无BGM/字幕/Logo及声音权限 | 先确定整段边界；一次定义高优先级限制 |
| ② 参考与起点 | 实际引用及控制维度；场景、实际在场角色、起始位置/姿态/视线/持物；轴线和必要空间锚点 | 时间轴必须从已确定的世界状态启动 |
| ③ 时间轴 Shot Blocks | 每镜取景、动作、机位响应、对白/VO、声音变化、结束与切换 | 只在发生处给指令，按先后执行 |
| ④ 末态与跨段承接 | 下一段真正依赖的位置、持物、视线或空间结果 | 必要时核对尾镜；简单结尾已写清则不重复 |
| ⑤ 局部稳定性限制 | 尚未在前文解决、会毁掉本段的少量风险；每条对应正确状态 | 只拦截真实误生成，不追加通用词库 |

场景的固定结构、光源和环境底声在①②定义；临时光线变化、进入/退出、声场变化在发生镜头定义。全局不写“他最终离开”这类会让模型提前跳到结果的剧情摘要；结尾指令只在末段或④出现。

不把完整人物心理弧、重复英文台词总表、镜头目的论文、校验表、修改说明、示例、未使用备选方案提交模型。不得把原样模板的括号或占位符提交。

## 7.4 镜头级顺序

**时间/镜号/连接 → 景别与机位 → 主体站位及当前状态 → 一个主要动作及必要反应 → 摄影机响应和画面变化 → 对白/VO与时间关系 → 环境声变化 → 结束状态/下一镜触发。**

动作和摄影机有依赖时合成短因果句：“角色开始……，摄影机随……；待……，摄影机停止在……”。不为守字段顺序而把同一动作写两次。无对白/无运动的镜头可以直接说“无对白”“固定”，未改变的底声继承。

景别至少写可见部位或取景边界；机位写相对主体的一侧、相对高度和观看方向。距离只有控制接触、视差或构图确有需要时说明，可用参照物或相对距离；不强制无法验证的厘米数。

“切镜原因”保留在内部镜头账本。执行句将原因编成触发：“手停在门把上后，硬切到……”，不输出“为了制造压迫感，切情绪镜头”。

## 7.5 视频提示词句法规则

下表是句法说明，不是可直接照抄的含占位符成品。最终填入正式名称、实际空间与动作。

| 类别 | 句法 | 自检 |
|---|---|---|
| 人物动作 | 正式名称＋当前状态＋刺激/起因＋起势＋主要动作＋停止条件/结果 | 谁动、向哪里、何时停；先后和并发分清 |
| 运镜 | 机位起点/高度＋人物动作触发＋路径/速度关系＋构图变化＋终点 | “跟随”必须回答从哪侧、取多大、是否同速、何时结束 |
| 景别 | 景别名＋入画部位/边界＋主体占位＋必要关系前景 | 承担信息的手/脚/物件在画内，不和裁切冲突 |
| 人物关系 | 两个正式名称＋前后/左右/距离＋互看对象＋谁改变/谁保持＋新位置 | 不能只写“占据上风”，必须有关系证据 |
| 人物调度 | 起始位置＋出发原因＋方向/短路径＋避让/停点＋新站位 | 进出画有落点，画面方向不无因翻转 |
| 反应镜头 | 已发生的刺激＋接收者起始状态＋一个可见变化＋保持条件＋切点 | 不先知，不重复没有增量的“震惊” |
| 插入镜头 | 已建立物件/部位＋归属及状态＋关键变化＋回接状态 | 插入不是新道具来源，不换手或重置动作 |
| 转场 | 触发事件＋硬切/遮挡/匹配方式＋新镜头起点 | 遮挡前后均明确；方式不能代替事件结果 |
| 时间轴 | 起止秒数＋镜号/节拍号＋唯一主要任务＋动作/声画定位 | 视觉轨无重叠/漏段；同镜节拍不得冒充硬切 |
| 连续性 | 承接已成立状态＋保持项＋本镜只改变项＋末态 | 下一镜不会重新起步、换边、复活已结束动作 |
| 禁止事项 | 具体误生成对象/动作＋正确替代状态或范围 | 不列不相关禁词，不把项目硬规则藏到末尾 |
| 环境声 | 实际声源＋远近/空间位置＋动作或时间触发＋变化/延续 | 不把无来源音乐换名为声音设计 |
| 对白 | 时间所属镜头＋正式发声者→对象＋现场/画外身份＋原文＋同步动作 | 一个发声事件只出现一次；看谁不改变谁在说 |
| VO | 原文顺序＋旁白身份＋覆盖的画面区间＋原文 | 画面可重构，叙述不能改成角色现场说话 |

### 句子质量的判断例

不充分：“镜头跟随赵宁。”

充分：“摄影机位于赵宁左前侧，腰部以上中景。赵宁沿走廊向打开的门迈两步，摄影机同向后退，保持腰部以上取景；门框从右侧进入画面。赵宁停在门前，摄影机同时停止。”

这里补的是侧别、取景、路径、相对速度、空间变化和终点；并非字越多越好。若路径或门框已在本镜明确，不再复述。

不充分：“陈越受到震撼。”

充分：“听完该句，陈越抬起的手停在胸前，没有继续伸向门口。保持陈越近景，直到陈越的视线从赵宁移向门。”

这只是句法示例，不授权任何正式项目新增该动作。最终提示必须从实际剧本编译。

## 7.6 动作与摄影机耦合的三种写法

- **人物先动、镜头响应**：角色开始移动/降低/转视线；摄影机跟随、降低或转焦；到达终点后停止。适合行动驱动场景。
- **机位先定、行为进入**：先给关系构图与空隙；角色进入、停下或改变距离；固定机位让新关系可读。适合阻挡、接近、公开冲突。
- **主体保持、观看权转移**：人物继续当前合理状态；焦点或切镜转向真正受影响的人；让反应完成。适合对白与认知戏。

不要一镜同时把“固定、推进、后撤、环绕”并列作为形容词。多个运镜阶段必须有清楚先后与终止条件；风险高时拆镜。

## 7.7 信息层级与去重

| 信息 | 写入频率 | 例外 |
|---|---|---|
| 项目身份/画幅/声音禁令/固定光源 | 每次独立提交的全局区一次 | 项目有明确变化时更新，不沿用旧值 |
| 参考职责、场景结构、轴线 | 每段一次 | 串扰高风险时在相关镜头最小提醒 |
| 当前主体、景别、机位、主要动作、结束/切换 | 每镜明确 | 同镜节拍可继承机位，写变化即可 |
| 临时站位、持物、朝向、光线阶段 | 起点定义；变化时和跨镜必要处写 | 关键交接明确前后归属，不能省到歧义 |
| 对白/VO | 每次发声事件在其所属区间一次 | 原剧本本来重复的台词保留为不同发声事件 |
| 环境底声 | 全局一次 | 逐镜只写新声源、远近或停顿中的变化 |
| 局部禁止项 | 靠近风险发生处或末尾一次 | 无BGM等项目硬约束在开头，不能只藏在局部 |
| 导演解释、风险评分、参考学习来源 | 内部或交付说明 | 不发送模型 |

压缩顺序：删赞词串 → 合并同义禁令 → 合并重复参考描述 → 删除重复台词总表 → 只保留有因反应。**不得压缩掉主体、因果、声音身份、关键证据与连接状态。**

## 7.8 最小执行外壳

以下仅为内部装配结构；编译后替换所有变量，按实际需要保留模块。

```text
生成约定：时长、画幅、取景形式、具体影像/声音要求及项目禁令。
参考与起点：真实绑定素材及职责；场景、在场人物、初始关系和轴线。

0.0–X.Xs｜镜头1
景别、机位、主体站位和当前状态。
主要动作；摄影机如何响应；可见结果。
对白/VO：正式发声者、类型、原文及发生时点。
环境声：只写本镜新增或变化。
结束状态；何时以什么方式进入下一镜。

X.X–Y.Ys｜镜头2
从上一镜结果进入新取景，描述本镜变化，其余按相同职责编排。

末态承接：仅补下一段依赖而尾镜仍未说清的状态。
局部限制：只保留尚未说明的真实失败风险。
```

R0可把每镜压成短段；R1增加必要的姿态、方向或接触前后；R2增加关键帧或分段绑定。画质和分辨率在全局按项目及实际入口配置，质量描述使用可验证的具体目标。

## 7.9 编译预检与输出就绪条件

| 检查 | 不通过时怎么改 |
|---|---|
| 文本保真 | 比较发声顺序、身份、类型和原文；不能因正式名称规则改动引号中的代词 |
| 全局完整 | 补本次实际时长/画幅、无BGM等硬规则；删除未填变量和不存在引用 |
| 因果可见 | 补承载转折的起势或关键接触；不能只写完成结果 |
| 部位入画 | 调整景别或插入，不要求头部近景展示画外手脚 |
| 时间可行 | 试读/估时；调整低价值段或拆段；结尾留可读状态 |
| 视觉轨一致 | 每个时刻只有一个有效镜头状态；同镜并发合并，消除重复时段的互相覆盖 |
| 镜间相接 | 起止位置、视线、持物和动作阶段相容；省略路程有明确剪接依据 |
| 镜头有效 | 说明每镜损失不得的功能；删掉换角度但不换信息的重复 |
| 权威不冲突 | 一维一最高来源；纠正不兼容的首尾、对白停顿和跨镜指令 |
| 提示效率 | 去重复和抽象话；保留最小充分的执行信息 |

输出“可提交”只表示文本与输入已就绪，不等于生成效果已验证。未获得实际成片时不得承诺达到某参考的画面质量。

# 8. 时间轴、镜头连接与动作执行

## 8.1 单一视觉时间轴

按 0.0–总时长连续排列主镜头区间；相邻镜头共用同一个边界时刻，不重叠不留不明空白。同一时刻的表演与摄影写在同一镜头内，避免分别再开“2–7秒摄影”和“2–5秒动作”两套主轴。

长镜头可在一个镜号下分节拍；注明不切镜、机位如何沿连续路径到达新位置。多镜头必须注明切换方式；不能只列多个时间段让模型自行决定是否切。

声音可跨视觉切点，但只保留一次发声事件，并写明起点、跨越哪个切点、结束位置。不得把跨镜声音重复写成两次对白。

## 8.2 结束状态 → 下一镜开始状态

连接句只传递必要变量：“赵宁仍停在门左侧；下一镜从陈越侧面看赵宁”；“杯子仍由赵宁右手握住，杯口朝上”。下一镜可改变景别和机位，不能无因改变人物位置或持物。

动作省略分清：不重要的步行可切到合理到达状态；若“首次迈步、主动贴近、松开手、让出路”是关系转折，应拍到该节点。跨空间/时间可用硬切、明确建立或有因匹配；不强制炫技遮挡、叠化或黑屏。

## 8.3 反应与镜内节奏

- 刺激 → 反应 → 新行为或关系结果；用这个顺序检查因果，再按当前内容设计镜头。
- 相同镜头返回时，应新增认知、动作结果或必要停顿价值。无增量的凝视优先合并。
- 关键台词前后的保持写在唯一发生处；镜头不必追每一个说话人。
- 长台词期间优先稳定站位和简单动作，利用接收者、细节或关系画面组织观看，不让人物一路走完台词。
- 背景状态服务事件：正常场景可继续活动，重大事件后按新状态反应，避免循环庆祝或全员同步转头。

# 9. 对白、旁白与声音

## 9.1 身份与文本

对白、画外对白、VO类型与原文由剧本锁定。正式名称用于发声标签与导演描述；引号内原文包括人称、口语、省略号和称谓保留。对白对象可以在画外；VO不驱动现场角色口型。

旁白描述的事件可以重新选择画面，但不能把旁白改成现场对白，也不能为逐句配图重演已经交代的内容。保留原顺序，避免模型额外解释。

## 9.2 声画跨镜

- 声音先行：明确哪个声音在何画面开始、何时揭示其来源；不只写“J-cut”。
- 尾音跨镜：明确哪句从前镜继续到后镜以及何时结束；不重复原文、不再次启动发声。
- 若选择“说完后保持反应再切”，同一句尾音就不能又要求跨该切点；须选择一个一致方案。
- 无声测试、静帧、字幕只能验证各自可见信息，不能验证音轨、口播完整性或具体混音。

## 9.3 无 BGM 与环境声

全局明确“背景音乐：无；不生成配乐、情绪铺底、无来源持续音”。环境声按真实场景与授权配置，远处人声保持不可辨内容，不能夹带新对白。

环境底声不每镜抄写。动作声绑定实际接触或移动；人物静止时不能凭空连续响脚步。焦点转移不自动触发全场静音；需要主观听觉收束时，只描述已有声源的远近变化，不增加所谓无旋律音乐层。

若模型对跨镜音频、精确停顿不稳定，先保证画面因果、保留剪辑余量，再用授权音轨后期完成。声音参考只在身份或节奏确需控制且真实可用时绑定。

# 10. 生成后质检、Take 判定与修正

## 10.1 证据检查

逐镜记录实际切点、景别、主动作、反应、关系、结束状态；区分提示要求、实际观察、导演解释和未验证项。隐藏剪接位置不确定时给区间，不伪报逐帧精度。

| 检查 | 通过条件 |
|---|---|
| 事实/人物/资产 | 人数、身份、服装与权威素材一致；必要剧情无变更 |
| 动作与证据 | 起因、关键过程、结果可读；重要部位确实入画 |
| 空间/视线 | 左右、持物、朝向、出入与轴线合理，人物看真实对象 |
| 节奏/表演 | 每镜或镜内节拍有作用，重复构图有增量，重要变化得到观看时间 |
| 结束状态 | 真正展示本段结果；好看的近景或遮挡不替代关系变化与结尾 |
| 对白/VO/声音 | 审听原文、顺序、身份、口型、跨镜与环境声；无未经授权BGM等内容 |
| 衔接 | 实际尾态可承接，错误结果不能因生成出来就升级为 Canon |
| 执行效率 | 无重复台词、冲突时间轴、遗漏硬约束或装饰性赞词堆叠 |

## 10.2 Take 判定

| 判定 | 条件及后续 |
|---|---|
| 接受 | 核心事实、因果、关系与项目硬规则成立，登记实际状态进入 Sequence Canon |
| 后期修复 | 文字、标识、混音、色彩或少量坏帧适合后期；修完重验，未修不能接受 |
| 局部编辑 | 只有局部变量错误且工具支持，保护正确层 |
| 重新采样 | 设计和参考合理，单次随机偏差为主，主要条件不变 |
| 重写方案 | 同类失败、动作过载、空间冲突或模型能力不足，改因果拆分/构图/参考/策略 |

## 10.3 单变量修正

先记录观察，再定位根因。优先只改一个主要变量；多个问题确认同源才联动。顺序：文本歧义/漏证据 → 起止状态 → 接触关键节点 → 参考串扰 → 空间或路径辅助 → 拆段/编辑/后期。重复失败停止盲目重采样。

声音问题不盲目重做正确画面；身份问题不重写已成立剧情；结尾事实失败不能只靠裁短或配乐掩盖。修正后重新按证据检查，只有接受状态更新 Canon。

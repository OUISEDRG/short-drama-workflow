# 剧梦 SD2.5 Prompt Compiler 适配 Skill

## 权威输入

1. 导演判断读取 `../ai-short-drama-director/SKILL.md` 及其按需参考。
2. 视频执行、动态拆段、时间预算、风险/R级、Reference Authority、五模块 Prompt Architecture、Take 与修正读取 `../sd25-video-prompt-compiler/SKILL.md` 及其按需参考。
3. 本文件负责剧梦素材映射、引用接口、平台文本清理与生成前兼容检查。

## 输入门禁

上游工作包必须包含：

- 权威剧本片段与原文对白/VO清单；
- L0/L1 项目硬规则与声音权限；
- 开始/结束状态及上一段已接受 Sequence Canon；
- 戏剧价值 A/A+/B 与独立的生成风险低/中/高、R0/R1/R2；
- 镜头功能、节拍、时间预算和 Reference Authority；
- 剧梦真实可用素材及逐字完整名称；
- 当前页面实时模型、分辨率、时长模式、字符限制和授权状态。

会改变身份、剧情、对白、必要信息、素材或空间结果的输入缺失时，状态标记为“未就绪”。

## 三层人物标识

- 导演分析层：使用当前项目角色表中的正式角色身份。
- Prompt 编译层：涉及外观、状态、入画或同人多状态时使用 `角色身份__视觉状态` 形式的内部角色实例。
- 剧梦引用层：使用当前项目素材库中检索到的实际完整素材名称，不由角色实例拼造平台名称。

每个角色实例必须映射到唯一完整素材名。项目显式正式名称字段负责角色身份；剧梦完整素材名称负责平台引用。

## 下划线命名与完整匹配

推荐命名：

- 人物：`角色身份_场景或阶段_造型或状态_EP适用范围`
- 场景：`场景名称_场景形态_素材类型_EP适用范围`
- 顶视图：`场景名称_场景形态_顶视图站位图_EP编号`
- 道具：`道具名称_状态或用途_EP适用范围`

所有平台引用均以剧梦素材库中真实存在、逐字一致的完整素材名称为绑定键。角色身份、时间阶段、场景、造型、服装、伤势、状态与 EP 适用范围共同决定候选素材是否可用。

## 剧梦引用准备

### 人物身份—素材绑定映射表

| 角色身份 | 角色实例 | 当前状态/造型 | 剧梦完整素材名称 | 本段使用 | 真实存在证据 |
|---|---|---|---|---|---|

### 其他素材绑定表

| 类型 | 核心对象 | 当前状态/形态 | 剧梦完整素材名称 | 本段使用 | 真实存在证据 |
|---|---|---|---|---|---|

同一角色在同一段存在多个视觉状态时，每个状态建立独立角色实例和独立完整素材名映射。

## 内容编译与唯一排版适配

本Skill与L2第7.3节负责内容输出；五项内容职责必须完整，但最终排版由《视频提示词输出规范_资产全名版》第24节负责。不要再按另一套五模块顺序输出重复稿。

适配后保留实际人物/场景/顶视图/道具引用、风格、场景、每镜时间轴和末态。每个实际连续镜头≤5秒，总时长按用户要求或已确认SRT，不固定单集或生成段长度。跨镜对白只发声一次。

不输出独立声音引用区，不新增声音文件@引用。人物引用自动附带的音频属于绑定依赖：记录来源与状态，绑定前后核对，不能按“多余附件”删除。无独立声音引用不等于无对白，正常现场与真实画外对白必须保留。

旁白只转对应画面；所有可见文字及实际人声只用 `main_language`。画面必要文字由模型直接生成，锁定确切原文和承载面，不转后期。工作说明、文件名、顶视图工作标注及内部编号不进入成片。画面错误与引用错误分别验收。

保留一维一个最高权威、真实完整素材名、单一时间轴和当前页面限制。平台字数/引用超限不能靠删台词、缩写资产或改时长掩盖。

## 引用顺序和成功证据

1. 处理文字字段；
2. 单独引用显式人物、场景、顶视图、道具等素材；
3. 根据人物身份—素材绑定映射表执行一键引用或当前平台等效流程；
4. 重新读取提示词框实际内容与引用芯片；
5. 逐名、逐实例核对完整素材名称、造型、状态和 EP；
6. 所有应绑定项验证成功后解除生成锁。

成功证据是平台真实引用芯片或卡片、逐字完整素材名和页面状态。人物身份、当前视觉状态与平台素材三者必须同时正确。

## 顶视图

顶视图是起始站位的高权威空间参考：

- 在剧梦素材库以场景名、形态、`顶视图站位图` 和 EP 检索；
- 使用完整素材名称绑定；
- 提取真实 HEX 辅助左右、前后、朝向和距离；
- 无匹配素材时记录检索结果，使用 v3.4 空间、轴线、视线和连续性规则；
- 顶视图是否成为成片镜头由本段剧情功能决定。

## 生成前适配检查

- [ ] 导演来源为 v3.4 核心规范。
- [ ] 内容满足L2第7.3节五项职责；排版仅按资产全名版第24节。
- [ ] 旁白画面化、正常对白保留、人物附带音频未删、无独立声音引用。
- [ ] 主语言唯一、必要文字直接生成、用户/SRT时长来源明确、实际单镜≤5秒。
- [ ] A/A+/B 与低/中/高风险、R0/R1/R2分别记录。
- [ ] 时间预算先于时间码。
- [ ] 每个实际素材使用剧梦完整名称。
- [ ] 同人多状态拥有独立角色实例和可逆映射。
- [ ] Reference Authority 一维一最高来源。
- [ ] 文字字段处理完成。
- [ ] 单独引用完成后执行一键引用。
- [ ] 页面实际状态已重读，所有应绑定项验证成功。
- [ ] L0 已授权生成，当前页面状态、模型、时长和计费已复核。

本地文本就绪与平台生成结果分别记录。

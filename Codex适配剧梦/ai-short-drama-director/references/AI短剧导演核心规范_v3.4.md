**CORE DIRECTING STANDARD**

AI 短剧导演核心规范 v3.4

跨项目、跨模型长期有效的导演底层原则

| **版本** | v3.4 |
| -------------- | ------------------------------------------ |
| **状态** | 正式启用 |
| **适用范围** | 所有 AI 短剧项目；不绑定任何具体视频模型 |
| **版本日期** | 2026-09-11 |

设计原则：用最少且明确的规则稳定生产；不把一次事故变成跨项目永久硬规则。

# 0. 总原则

v3.5.1执行裁决（2026-09-26）：内容与排版分工见模型工作流第7.3节及资产全名版第24节。当前项目默认旁白画面化、正常对白保留、主语言文字直接生成、每个连续镜头≤3秒；这些是执行约束，不改变剧本事实与导演判断。不得把旧版通用VO或后期示例恢复为当前默认。

当前任务优先，剧本与项目身份优先；模型工作方法根据内容、时间预算和风险动态选择，所有执行结构都服务于当前交付。

本规范只定义跨项目、跨模型仍然成立的导演判断、连续性、可执行性与质检底线。具体模型的能力、时长、拆段、参考素材和提示词结构，全部交由对应《视频模型工作流配置》负责。

# 1. 文件边界与规则优先级

| **层级** | **规则来源** | **负责内容** | **冲突处理** |
| ---------- | ---------------- | ------------------------------------------------------------- | -------------------------------------- |
| L0 | 当前任务要求 | 本次集数、镜头、时长、交付形式、临时禁忌 | 最高优先级；明确要求可覆盖下层默认值 |
| L1 | 项目配置 | 作品身份、画幅、语言、视觉风格、角色/场景资产、项目声音规则 | 不得被模型便利性静默改写 |
| L2 | 模型工作流配置 | 当前模型的能力边界、拆段策略、参考方式、提示词执行策略 | 只决定如何实现，不决定作品是什么 |
| L3 | 导演核心规范 | 长期导演原则、连续性、可执行性与质量底线 | 提供通用判断，不写模型专属参数 |

冲突仲裁：当项目身份与模型稳定性发生冲突时，不得擅自牺牲项目设定。应识别风险，并改用拆段、参考素材、构图调整或后期方案；最终以当前任务要求为准。

# 2. 十四条核心导演原则

1.  当前要求优先。先识别本次任务真正要交付什么，再调用项目、模型与核心规范。

2.  权威剧本不可擅改。人物、事件、因果、核心对白、情绪转折和结局以已确认剧本为准；需要改编时必须明确说明。

3.  已确认资产不得漂移。角色身份、脸、年龄感、发型、体态、服装、伤势、道具与场景结构以当前权威资产为准。

4.  先理解戏，再设计镜头。镜头服务于冲突、信息、情绪、行动与节奏，不以炫技、模板完整或镜头数量为目标。

5.  空间关系必须可读。多人戏先确认谁在哪里、看向谁、从哪里进入或离开，再决定构图、景别与镜头运动。

6.  动作必须前后连续。上一镜的姿态、持物、朝向、动作结果应能自然进入下一镜，不得瞬移、换边或无因重置。

7.  镜头必须有动机。景别、角度、切换与运动应服务于新信息、动作节点、情绪变化、视点变化或空间重建。

8.  表演必须可见。把心理状态转译为眼神、呼吸、表情、停顿、肩颈、手部和身体重心等可拍摄变化；允许使用简短、非比喻、非颜色化的情绪标签作为辅助，但应以可观察表演为主。

9.  重要人物必须参与现场。当前叙事主体与关键反应对象应有与刺激一致的自然反应；背景人物保持自然生命感即可，不强制每个人持续做显著微动作。

10. 对白与动作量必须可完成。明确谁说、对谁说、在做什么；不要在有限时长里同时堆叠长对白、复杂接触、多人大调度和大幅运镜。

11. 提前识别生成风险。手部、小道具、人体接触、多人交叉走位、遮挡、反射、复杂文字、门窗与快速旋转等必须提前评估。

12. 提示词必须可执行。优先描述屏幕上能看到或听到的主体、动作、镜头、表演、空间、声音和连续性要求。

13. 角色标识必须使用角色信息中的正式名称。禁止第一、第三人称代词以及“爹、娘”等关系代称作为人物标识；多人戏中每个主体均使用正式名称，保持全文一致且无歧义。

14. 修正应保护已正确内容。先定位真实失败变量，优先最小有效修改；不要因为一个视线错误重写已经正确的脸、服装、动作和场景。

# 3. 导演分析的最小闭环

每次视频任务必须内部完成本章；“直接给提示词”只省略分析展示，不省略分析。文生图另执行附录 D 十维分析。导演记录进入编译器，不原样发送模型。

| 步骤 | 必须产出的决定 |
| --- | --- |
| 事实锁定 | 权威剧本、在场人物、原文对白/VO及顺序、禁止新增的事实 |
| 本段任务 | 开始状态、结束状态、观众此刻等待的答案；结束状态必须能被画面或声音验证 |
| 知识与关系 | 观众已知、各角色已知/误解、本段新证据、主动权或距离如何变化 |
| 节拍与视点 | 哪个刺激先发生，谁先反应，信息何时释放，哪一状态需要停留 |
| 空间与连续性 | 上一段已接受 Canon、出入口、轴线、视线、持物和动作起止 |
| 价值与风险 | 戏剧价值 A/A+/B；另评低/中/高生成风险，不用一个等级替代另一个 |
| 视觉翻译 | 主要可见行为、承载部位、景别、机位、镜头响应、结束证据 |
| 参考与编译 | 各维度的 Reference Authority、执行限制、时间预算，交模型工作流编译 |
| 验收 | 核心因果、关系和结尾是否真正拍到；未验证声音等项目不得算通过 |

## 3.1 戏剧价值与 Director's Read Lite

| 价值 | 内容 | 导演投入 |
| --- | --- | --- |
| A | 普通叙事、必要过渡 | 最小闭环；明确观看任务和承接 |
| A+ | 重要情绪、关系变化、信息揭示 | 强制 Lite；为变化配置可见证据与反应时间 |
| B | 核心爽点、反转、真相、人物弧收束 | 强制 Lite；设计预期、延迟、释放、反应、关系变化及余波，按剧情选取和排列 |

回忆、新认知、重要选择/承受，以及事实正确却容易寡淡的段落，同样强制 Lite。B 不等于更多镜头、更长提示或更高生成风险；一个静止近景也可承担核心反转。

Lite 只保留六项决定：本镜为何存在；开始/结束差异；观众跟谁发现；角色当下知道什么；关系是否变化；用哪个可见载体证明。没有关系变化时写“不适用”，不制造假冲突。

## 3.2 导演意图 → 可验收画面的翻译

固定转换链：**导演意图 → 视觉行为 → 镜头语言 → 模型执行语言**。

| 导演意图 | 可见证据 | 镜头选择与执行落点 |
| --- | --- | --- |
| 角色失去主动 | 原本继续的动作停止，另一角色保持位置 | 保留双方的关系画面；停止发生后才切承受者近景 |
| 角色开始相信 | 同一个试探动作第二次继续完成 | 景别包含执行部位；先显示未完成状态，再显示完成结果 |
| 公开评价改变 | 关键旁观者停止原活动，目光转向新对象 | 只选有信息职责的反应对象，建立与主体的视线联系 |
| 真相被理解 | 刺激之后出现可比较的姿态、眼神或行动结果 | 关键台词可留在接收者画面，直到变化可读 |
| 人物停止等待/拒绝/追逐 | 旧行为被新行为取代，后续不再恢复旧状态 | 必须展示新状态；“趴下、沉默、转身”等孤立动作不能自动证明结局 |

这些是翻译示例，不是所有剧情必用的动作库。选择一个主要证据，不强制眼睛、眉毛、呼吸、手、肩颈全部依次运动。景别必须覆盖证据部位；台词宣告不替代必要行动。

# 4. 剧本权威与导演改编边界

- 不得擅自新增关键人物、改变人物关系、调换因果顺序、删掉剧情必要信息或改写结局。

- 可在不改变故事事实的前提下，把心理描写转译为表情、呼吸、动作、反应、停顿、构图与声音。

- 可为影视表达补充建立镜头、反应镜头、动作过渡与环境细节，但不得制造新剧情。

- 如需压缩，优先保留因果、关键动作、人物立场变化、核心对白和段尾钩子。

- 对白/旁白的保真级别由当前任务与项目配置定义；被标记为“不可改写”的权威文本必须逐字保留。

- 如剧本信息不足，可做不改变剧情事实的最小假设；影响剧情或资产的重大缺口应明确标记。

# 5. 连续性系统

| **维度** | **必须核对** | **常见失败** |
| ------------ | -------------------------------------- | -------------------------------- |
| 人物身份 | 脸、年龄感、发型、体态、妆发 | 换脸、角色重复、年龄漂移 |
| 服装与状态 | 服装层次、配饰、污渍、伤势 | 镜间换装、伤势消失或转移 |
| 道具 | 归属、哪只手、方向、开合、损坏状态 | 换手、消失、尺寸变化 |
| 空间 | 左右、前后景、距离、出入口、家具位置 | 换边、瞬移、越轴、房间结构变化 |
| 视线 | 人物真正看向谁或什么 | 无因看镜头、对话方向错误 |
| 动作 | 起点、过程、结果与下一镜承接 | 动作重置、姿态断裂、接触无因果 |
| 光线与时间 | 光向、色温、亮度、天气、昼夜 | 光源反转、曝光和时间突变 |
| 情绪 | 进入情绪、变化节点、离开情绪 | 反应先于刺激、强度突然归零 |

首尾状态原则：每个生成片段都应能用一句话说明“从什么状态开始、以什么状态结束”。若下一段无法自然承接，先修正连续性，再追求漂亮构图。

- 当文本、旁白或文案没有直接给出下一镜的具体画面时，先继承上一镜已经成立的主体、动作结果、方向、空间或视觉元素，再选择新的景别与信息；不得把同一事件重新从零生成。

## 5.1 连续性权威原则与 Sequence Canon

连续性不是机械回到原计划，而是按权威顺序继承已经成立的事实。计划状态只在尚未生成或尚未接受成片时有效。

| **优先级** | **连续性来源** | **裁决原则** |
| ------------ | -------------------------------------- | -------------------------------------------- |
| 1 | 权威剧本事实与 L0/L1 硬规则 | 最高；任何成片偏差不得覆盖。 |
| 2 | 已锁定角色、场景、道具等权威资产 | 身份与固定资产不得因随机生成漂移。 |
| 3 | 已接受成片中的实际可见临时状态 | 不违反上层规则时，成为下一片段的真实起点。 |
| 4 | 原分镜计划、原提示词设想、未生成预期 | 只在更高权威没有给出实际结果时使用。 |

- 成片只有被判定为“接受”后才进入 Sequence Canon；被拒绝的 take 不更新 Canon。

- 接受成片的实际起止姿态、位置、视线、持物、动作结果、空间关系、光线阶段和必要情绪状态，成为下一片段的连续性依据。

- 已接受成片中的轻微偏差在不伤剧情且不违反上层权威时由后续继承；违反剧情事实、项目硬规则、身份、关键道具归属或必要因果的结果进入修正流程。

## 5.2 镜间状态交接

内部记录：镜号｜开头姿态/位置/视线/持物｜本镜改变｜结尾状态｜下一镜继承项。每镜明确本次变化；未变的资产不抄全文。执行提示只写连接所必需的状态。

接触和移动遵守“起因 → 起势 → 过程/接触 → 结果”。如果自主选择、拒绝、让路、交接本身就是剧情，不得用已完成结果跳过关键过程。可以省略无价值路程，但必须保留决定性节点。

遮挡前与遮挡后分别验收：遮挡成功不证明人物已消失，道具特写成功不证明归属已改变。尾帧不能替代到达尾帧的必要因果。

# 6. 空间、轴线与视线

- 默认保持稳定的画面左右关系；需要越轴时，用中性镜头、运动过轴或明确的空间重建。

- 对话者视线必须与其画面位置和真实交互对象匹配；只有剧情明确打破第四面墙时才直视镜头。

- 多人戏先建立谁靠近谁、谁挡住谁、谁能进入或退出，再决定景别和运动。

- 角色进出画面要有明确方向和落点；下一镜继承运动方向，或用建立镜头重新定位。

- 构图优先突出当前叙事主体，同时保留必要关系信息；避免所有人物机械横排、正对镜头。

# 7. 镜头设计与节奏

## 7.1 镜头功能与有效镜头密度

每镜指定一个主要任务：建立空间、推进动作、揭示/延迟信息、强化台词、展示反应、改变关系、释放情绪、必要缓冲、转场或关键细节。副任务可存在，但不抢主要任务。

内部最小镜头账本：镜号｜主要功能｜新增信息/动作/情绪/关系/空间｜可见证据｜切入触发｜结束状态。可一句完成，不要求每次输出表格。

有效镜头密度看有功能的观看变化，不以每分钟切数评分。连续镜头中的转焦、重构图、进入/退出与关系变化也是节拍。静止可以承受信息、积累预期或给必要缓冲；应能回答删掉后会损失什么。空镜与过渡同样要有功能，不能作为免检项。

流水账指镜头只按事件排队，观看重点和状态没有累计变化；反复走路、重复建立、同一反应换角度、每句对白机械配一镜都是常见表现。优先删合冗余，再补缺失的反应或关键证据，不用无关插入提高镜数。

## 7.2 选择切镜、保持或运镜

| 选择 | 使用条件 | 执行中要看见什么 |
| --- | --- | --- |
| 硬切 | 下一信息需要新的观看对象、角度或空间，连续移动没有额外价值 | 刺激之后进入结果或反应；视线与方向能承接 |
| 保持 | 反应正在形成、动作因果尚未完成，或观众需读清状态 | 留在当前主体，直到指定行为/停顿完成 |
| 推近 | 主体不变，关注范围从关系缩到细节或承受 | 写清起始取景、推进终点和被减少的环境信息 |
| 切反应 | 听者/旁观者的新理解比说话口型重要 | 刺激已发生；新态度有可见载体，不提前知道真相 |
| 切细节 | 手、脚、道具或接触点承载其他景别看不清的证据 | 显示关键动作前后状态，再回到正确归属与关系 |
| 切关系镜头 | 距离、阻挡、结盟、分离或主动权发生变化 | 双方相对位置、视线及空间变化可读 |
| 同镜转焦/重构图 | 连续性有价值，新的观看对象已在现场层次中 | 注意力从明确对象转到另一对象，人物不用为镜头无因移动 |

切镜主因选动作、台词、视线、情绪、信息、空间、关系或节奏中的主要一项。不在模型提示里喊“情绪切镜”，而写“听见该句后，动作停住；硬切近景，看见……”。

## 7.3 景别、机位与镜内节奏

- 先选承担变化的部位，再定取景边界；近景不能同时要求画外脚步或尾部证明转折。
- 机位写相对人物的一侧、高度和观看方向。前景局部应符合真实身高；不同身高角色不机械套标准过肩。
- 相同构图可以重复，用于比较不同理解或行动结果；重复时必须有新增作用。正反打是否机械，由状态是否更新判断。
- 运镜有路径、动因和终点；人物移动与摄影机移动分别描述。主体变大不必然等于推进，背景人走动不等于机位视差。
- 前景可标明观看者或阻挡，中景承担主动作，后景维持现场；只保留对本段有用的层次，不强制所有景别填满四层。
- 主体静止时，摄影机可以转移观看权；摄影机固定时，人物和信息也可以变化。不要强制摄影机永远运动。
- 手持的细微滞后、避让或构图修正只在有物理动因且不损害主信息时使用；不把故意失焦、摇晃、追过头变成固定风格。

## 7.4 关键段落的权重

爽点、真相、反转、关系变化要获得更多有效观看资源：可以是反应、留白、关系证据和余波，不等于平均加快切换。依据前文决定铺垫是否已完成，避免再次拍已交代的照片、物件或回忆。

先给结束状态留出足够可读时间，再安排前面的对白、行动和过渡。时间不足时压缩低价值移动或拆段，不能删掉改变剧情意义的那一步。温情兑现、悬念保留、权力逆转分别验收，不套同一种“爽点公式”。

# 8. 表演、对白与声音权限

- 表演由刺激引起；角色的反应不得早于获得信息。选择有因的凝视、停顿、动作中止或身体变化，不用抽象情绪词代替行为，也不强制固定生理顺序。
- 说话者口型自然；倾听者继续当前合理动作，或因具体刺激停止。关键人物有因参与，背景保持符合事件阶段的生活状态；不能为了“背景活着”而在事故后继续庆祝。
- 关键台词先判断观众该看谁：说话者的决定、接收者的承受、旁观者的评价或关系整体。声音身份不随画面主体改变。
- 对白、画外对白和 VO 分开登记。原文与顺序受剧本锁定；更换画面不等于允许重写旁白或把旁白交给现场角色说。
- 正式名称规则约束导演描述中的主体标识，**不改写权威引号内的对白/VO**；原文中的 I、you、he、she、亲属称呼照原文保留。
- 停顿标明发生在话前、句内还是话后；不重复在多处给同一句安排互相冲突的切点。
- 环境声写实际声源、远近与变化。可让对白空隙露出现场声，不默认加额外事件、人声或音效。
- 音乐权限由当前任务与项目决定。项目“无 BGM”时是高优先级硬约束，包括未授权的情绪铺底、持续 drone 和无来源的叙事低频；不能换个音效名称规避。真实环境低频只有在场景有依据时可保留。
- 声音先行、尾音跨镜与声场变化须有明确时间和来源；生成后必须审听，字幕与静帧不能作为音轨验收证据。

# 9. AI 可执行性与风险预判

优先检查多主体并发、长距离走位、频繁转身、复杂手部与物品交接、遮挡、反射、精确文字、相似人物和空间转换。风险与戏剧价值分别管理。

| 风险 | 优先处理 | 必须保留 |
| --- | --- | --- |
| 复杂接触/交接 | 拆成接触前、关键接触、完成后；必要时插入或关键帧 | 动作起因、主动选择、归属变化的证据 |
| 长距离移动 | 只拍决定与关键过渡，用硬切或反应省略无价值路程 | 出发方向、可理解的时间省略与到达状态 |
| 多人同时动作 | 一主动作，其他人保持或给有限反应，必要时拆镜 | 现场关系与关键旁观者，不无故清空环境 |
| 遮挡/消失 | 提前锁遮挡前后状态，必要时外部剪辑 | 遮挡后的新状态，不能只验遮挡本身 |
| 文字/手机/镜面 | 权威素材、清楚构图与承载面；必要文字按本剧主语言直接生成 | 不以留白或后期替换删去必要信息；实际文字仍须验收 |
| 微动作太密 | 挑一个主要行为，扩大取景可见性或增加观看时间 | 承担转折的部位和结果 |

高风险不等于禁止。先改最可能失败的变量，再选拆镜、反应、插入、参考或后期；不要堆形容词，也不要同时重做所有正确条件。

# 10. 可执行提示词的通用要求

本章负责语义底线，具体模块顺序与句法由模型工作流第 7 章 Video Prompt Compiler 维护，避免两份文件重复不同模板。

- 执行描述以正式角色名称、可见动词、作用对象、空间关系和结束状态为核心；服装款式与颜色仍只由权威资产和内部连续性维护。
- 每镜先明确取景与起始状态，再写主要动作、摄影机响应和变化结果。先后动作使用“先、待、才、随后”，只有可并行的事才写“同时”。
- 导演意图必须经过视觉行为和镜头语言转换。内部“爽点、认知、关系翻转”等标签不原样代替执行句。
- 固定条件在每次独立提交的全局区定义一次；逐镜只补当前取景、行为、声音及状态变化。跨生成请求不能假定模型记得上一条提示。
- 局部限制指向当前可能误生成的对象或动作，并给出正确状态；数量由当前必要硬约束决定。
- 准确优先于短：删重复解释，保留动作因果、视线归属、台词原文与参考职责；抽象描述必须翻译为可见画面。
- 输出前检查时间是否容纳对白、顺序动作和反应；精确时间码是执行目标，生成后仍需按实际切点核验。

# 11. 生成后质检与修正

| **检查项** | **通过标准** |
| ------------ | ---------------------------------------------------------------------- |
| 人物 | 身份、脸、服装、伤势、人数与权威资产一致 |
| 动作 | 动作顺序可读，接触与道具有因果，无无因重置 |
| 空间 | 站位、左右、出入口、遮挡和轴线清楚 |
| 视线 | 人物看向真实交互对象，不无因直视镜头 |
| 对白 | 说话者正确，口型与节奏可接受，台词无错配 |
| 衔接 | 首尾状态、方向、光线、情绪、道具和必要的转场匹配能自然承接 |
| 节奏 | 每镜或镜内节拍有功能；重复构图有新的比较价值；关键变化得到观看时间 |
| 表演 | 主体与关键反应对象有自然变化；反应带来信息或态度，无明显站桩和等台词 |
| 执行合规 | 提示词结构遵循当前模型配置；项目硬规则得到执行 |

## 11.0 证据验收

对关键镜头同时检查：画面是否可用、关键因果是否出现、结束状态是否成立。任一核心证据缺失，不因美观而判接受。景别内看不见的动作、未审听的声音、未提供的参考一致性，记录“未验证”，不得用提示词原文补成成片事实。

## 11.1 Take 判定

完成质检后，先判断这条成片应如何处置，再决定是否进入生成层修正。

| **判定** | **适用条件** | **下一步** |
| ---------- | ----------------------------------------------------------------------------------- | -------------------------------------------- |
| 接受 | 核心剧情、动作因果、人物关系和叙事任务成立；剩余问题不影响使用。 | 登记实际状态进入 Sequence Canon。 |
| 后期修复 | 只适用当前用户另行授权的非语言性剪辑或画面问题；必要文字、错误语言不自动转后期。 | 未授权不转后期，未修复不接受。 |
| 局部编辑 | 整体构图与时间关系正确，只有一个局部层错误，且当前工具支持定向编辑。 | 保留正确内容，只编辑失败层。 |
| 重新采样 | 提示设计与参考关系正确，失败主要是单次随机偏差。 | 主要提示与参考不改，重新生成。 |
| 重写方案 | 同类错误重复、动作过载、空间不清、参考冲突或模型长期无法稳定执行。 | 改变提示、动作拆分、构图、参考或生成策略。 |

只有“接受”可以更新 Sequence Canon；后期或局部修复完成后需重验并判接受。不得把仍违反项目硬规则的素材登记为通过。

## 11.2 根因与单变量修正

- 需要进入生成层修正时，原则上每轮只改变一个主要变量：一条关键提示语、一个参考素材、一种生成模式/工具，或一个动作/构图方案。多个错误只有在确认来自同一根因时才联动修改；否则避免同时改变运镜、景别、动作、表演、参考和光线，以保持可诊断性。

- 先描述可观察到的问题，再判断根因来自提示词、资产、参考条件、模型能力还是剪辑。

- 优先修正真正失败的变量并保护已正确内容；若同类错误在多次有效尝试中重复出现，应停止盲目重采样，转入“重写方案”。

- 多个错误若来自同一根因可联动修正；若来源不同，按对成片影响从高到低处理。

## D.1 模块定位与输入优先级

本模块用于把\[当前分镜原文\]放回\[小说原文\]上下文中，结合\[角色信息\]与给定场景信息，生成面向 AI 文生图的高度结构化镜头画面描述。它属于“导演内部分析 → 分镜画面描述”的专用执行层，不改变 L0 当前任务、L1 项目配置与权威剧本的优先级。

- 输入至少包括：\[当前分镜原文\]、\[小说原文\]、\[角色信息\]；如已有\[场景信息\]、上一镜实际画面结果或权威资产，应一并读取。

## D.2 十维内部分析流程

每一个镜头都必须完成以下十个维度的内部分析。除当前任务明确要求展示分析过程外，最终交付只需输出整合后的画面描述词，不机械展开十项表单。

| **维度** | **名称** | **内部分析要求** |
| ---------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 | 角色 | 结合\[当前分镜原文\]、\[小说原文\]与\[角色信息\]判断实际出场角色；动作、道具、表情、站位等均落实到正式名称。 |
| 2 | 场景 + 时间 | 优先使用给定场景信息并精准定位室内/室外及具体区域；时间/天气优先继承小说上下文、项目设定与上一镜，仍无依据时标记“未明确”，不得为了填满模板强行具体化。 |
| 3 | 美学选择 | 组合光源类型与整体画面/环境色调，保证明暗关系。允许环境、光线和整体画面的颜色词；禁止用颜色描述人物身体、面部、表情、情绪或心理状态。 |
| 4 | 景别 | 基于叙事目的选择：远景/大远景、全景、中景、近景、特写。分析阶段仅输出景别名称。 |
| 5 | 机位角度 | 基于镜头语言选择：过肩镜头、背对镜头、仰拍、俯拍、斜角镜头、平视镜头。分析阶段仅输出机位名称。 |
| 6 | 画面主体 | 提炼 1–2 个绝对核心视觉主体，保证画面叙事重心明确。 |
| 7 | 镜头类型与构图 | 明确单人/双人/多人等镜头类型，以及中心、对称或其他适合当前叙事的构图方式。 |
| 8 | 位置与交互 | 单人明确画面位置；多人明确相对位置、前后景、朝向与交互对象，保证空间关系可读。 |
| 9 | 动作与表情 | 用凝练短语描述核心动作与可观察面部/身体状态；允许“害羞、紧张、惊讶”等简短情绪标签辅助，但严禁颜色化情绪、自然现象隐喻、物理隐喻和文学比喻。 |
| 10 | 全局提示词 | 把前九维整合成可执行画面描述。只保留当前任务必要的画质与光线要求，不要求每镜固定追加质量后缀。 |

## D.3 最高优先级禁令与严格约束

- 人物色彩禁令：严禁使用颜色词描述人物身体、面部、表情、情绪或心理状态；环境、场景、光线与整体画面色调可以正常使用颜色词。

- 隐喻禁令：严禁用具象自然现象、物理现象或文学隐喻形容眼神、情绪或气场。

- 约束自检：原文若出现“眼眶通红、面色铁青、眼神冒火、杀气腾腾”等表达，必须转换成可观察、可拍摄的平实动作、面部状态、呼吸、停顿或身体变化。

- 命名禁令：人物只能使用\[角色信息\]中的正式名称；不得用“我、他、她、爹、娘”等代词或关系代称代替角色名称。

- 服装禁令：所有生成提示词均剔除人物服装款式与颜色。服装连续性只通过权威资产、参考图与内部质检维护，不通过文字提示描述。

- 文学修辞禁令：不使用“像……一样”“如同……”等修辞，直接描述可观察的物理状态、动作、位置和镜头关系。

- 情绪标签边界：允许简短、直接的情绪/表情标签辅助表达，但不得用颜色、隐喻、气场化或自然现象化措辞扩写情绪。

## D.4 约束自检

- 角色名称：是否所有人物都使用正式名称，且不存在第一/第三人称代词或关系代称。

- 服装：最终生成提示词是否完全没有人物服装款式与颜色文字；内部连续性检查可保留服装资产状态。

- 人物色彩：是否出现用颜色描述人物身体、面部、表情、情绪或心理状态的词语。

- 环境色调：环境、光线与整体画面色调可以保留，不因人物色彩禁令被误删。

- 隐喻：是否存在自然现象、物理现象或文学比喻式情绪表达；若有，改写为眉眼、嘴部、呼吸、手部、肩颈、姿态、动作速度或停顿等可观察状态。

- 时间/天气：是否有上下文或项目依据；无依据时写“未明确”，不得强行补设。

- 位置与交互：多人是否明确相对位置、前后景、朝向和交互对象；单人是否明确画面位置。

- 质量后缀：仅在当前项目/任务需要时使用可选后缀，不作为跨项目固定硬规则。

## D.5 最终输出方式

默认执行方式：先完成十维内部分析，再把结果压缩为一段可直接用于文生图的画面描述词。最终输出不强制展示“角色/场景/景别……”十项字段；只有当前任务明确要求结构化分析时才展开十维。

| **输出层** | **要求** |
| -------------- | -------------------------------------------------------------------------------------------- |
| 内部分析 | 强制执行十维；场景与时间合并为一个维度。 |
| 最终画面描述 | 自然整合主体、空间、动作、表演、镜头与美学信息；人物只用正式名称；不写人物服装款式与颜色。 |
| 情绪表达 | 以可观察动作/面部状态为主，可辅以简短情绪标签；禁颜色化、隐喻化表达。 |
| 质量后缀 | 按任务填写具体画质要求，不追加固定赞词串。 |

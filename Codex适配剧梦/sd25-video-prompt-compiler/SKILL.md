# SD2.5 视频 Prompt Compiler

## 使用边界

本 Skill 是 L2 视频模型执行层。它决定如何把导演方案变成模型可执行请求，不决定作品身份、剧情事实或平台授权。

- 上游事实包来自 `../screenplay-prebreakdown-analysis/SKILL.md`。
- 上游导演决策来自 `../ai-short-drama-director/SKILL.md`。
- 表演执行语言按需读取 `../cinematic-acting-execution-library/SKILL.md`。
- 剧梦引用和页面兼容交给 `../dreamina-sd25-prompt-adapter/SKILL.md`。

## 必读规范

编译、拆段、诊断生成失败或进行 Take 修正前，完整读取 [视频模型工作流配置_SD2.5_v3.4.md](references/视频模型工作流配置_SD2.5_v3.4.md)。同时读取资源 `reference.shot_language`，核对导演交付的camera_strategy、逐镜camera及双端connections。其中的模型能力信息是有日期的资料，实际可用时长、参考输入、编辑入口、字符限制和计费必须以当前界面重新核对。

## 输入门禁

v3.5.1：读取本项目主语言和最新决定；旁白仅画面化，正常对白及人物附带音频保留，无独立声音引用；必要画面文字直接生成。总时长按用户要求或已确认SRT，每个实际连续镜头≤3秒。

至少需要：

- 当前 L0/L1 要求和权威剧本片段；
- 原文对白、VO/OS 清单及声音权限；
- 开始状态、目标结束状态和上一段已接受 Sequence Canon；
- 导演任务、镜头功能、主要视觉证据和空间关系；
- 人物身份与角色实例，但不得虚构平台完整素材名；
- 当前模型入口可验证的能力和限制；无实时证据时明确标记未知。

会改变身份、剧情、对白、必要信息、空间结果或授权范围的缺口不得自行补写。

## 编译工作流

v3.7 G02先读取 `layout.final_prompt`：默认20–30秒独立分镜、每镜≤3秒、去完整资产名≥2501汉字。角色身份→当前视觉实例→真实绑定解析→完整资产名→B区唯一执行稿，正文不得回退角色简称。缺绑定保留计划稿。导演字段与因果证据是“最小完整”的必保内容；删冗余不能删观看任务、视觉递进、独特镜头功能、刺激反应、空间关系、声音身份或末态钩子。

编译后以 --require-profile g02_cinematic_fullname_v2 运行整集清单/实际唯一B区正文校验并审查警告，再交付。时长、详细度或功能例外必须引用当前项目/L0、SRT、剧情或现场限制的具体来源，不凭“更自然”“简单写”自行降级。参数中的默认范围/字数若由L0明确覆盖，落实到清单的segment_duration_exception/detail_override以便审计，保留权威来源。

1. 复核事实和导演意图，分开记录戏剧价值、生成风险与控制深度。
2. 按对白、顺序动作、反应、空间变化和风险估算时间预算，由当前内容决定是否拆段及镜头粒度。
3. 为身份、外观、服装、空间、动作、道具和声音分别确定唯一最高权威，消除 Reference Authority 冲突。
4. 将选定camera.execution与对应out_execution/in_execution、声桥执行句完整写入所属镜头，展开起点、路径、速度、主体关系、画面变化、终点与切点；不输出独立补充方案、不只写方法名、不改执行字段迎合错误正文。缺选择或不可执行时回导演修订。将镜头功能编译为连续时间轴，明确刺激、动作、镜头响应、结束证据和跨段承接。
5. 完成详细规范第7.3节五项内容职责；与剧梦适配共同负责内容。最终排版只按《资产全名版》第24节，不再另出五模块重复模板。
6. 只保留当前请求需要的限制；移除占位符、教学说明、未用备选和重复对白。
7. 生成失败后先根据实际证据区分提示词、参考素材、模型能力、平台状态或审核原因，再选择局部编辑、重新采样、最小改写、拆段或重写方案。

## 输出合同

交付至少包含：

- 当前段边界与时间预算依据；
- 低/中/高生成风险与 R0/R1/R2 控制深度；
- Reference Authority 裁决；
- 满足L2第7.3节内容职责、按资产全名版第24节排版的唯一视频Prompt；
- 计划末态、下一段承接条件和需由平台适配层完成的绑定项；
- 未验证的模型能力、字符限制或页面条件；
- 修正任务中的失败变量、保护项和推荐处理路径。

最终 Prompt 是模型执行稿，不是导演分析报告。分析可以隐藏，但其事实、因果和连续性约束不能省略。

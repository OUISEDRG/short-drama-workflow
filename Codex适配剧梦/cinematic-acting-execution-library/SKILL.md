# 统一电影表演控制 2.0｜Acting Execution Library

## 职责边界

本文件是执行词库，不是导演大脑。

- 戏剧任务、A/A+/B、Director's Read Lite、主要视觉证据、镜头选择与关系变化由 `../ai-short-drama-director/SKILL.md` 决定。
- 动态拆段、时间预算、风险/R级、Prompt Architecture 与句法由 `../sd25-video-prompt-compiler/SKILL.md` 决定。
- 本文件只把已选中的表演证据写成模型可执行语言。

每个节拍由导演任务选取一个主要可见证据，必要时再配一个支持信号；眼神、面部、呼吸、手部、姿态和距离按当前景别与因果选择。

## 执行原则

1. 刺激先于反应；角色不得在获得信息前提前表演结果。
2. 表演服务对象、目标、障碍和关系，不表演孤立情绪。
3. 用可观察状态表达：动作开始/中断/完成、注视目标、呼吸、姿态、重心、距离、持物和停顿。
4. 近景动作更少、更细；景别必须覆盖承担证据的部位。
5. 长对白期间稳定站位和主动作，让接收者反应或关系画面承担观看变化。
6. 强刺激留下惯性，不能下一镜无因归零。
7. 同一角色身份可有多个视觉实例；表演文本使用当前角色实例，剧梦引用另映射到完整素材名。
8. 引号内权威对白不因正式名称规则而改写。

## 最小表演决策

对当前需要表演的主体内部确认：

- 对象：正在影响、躲避、观察或承受谁/什么；
- 目标：此刻要完成的可行动目标；
- 刺激：哪个台词、动作、物件或发现触发变化；
- 主要证据：最能证明变化的一个行为；
- 支持信号：只有需要时选择眼神、呼吸、手部、姿态或距离中的一个；
- 结束状态：观众能看到的动作/关系结果；
- 保持项：未改变的位置、持物、朝向和身份状态。

这些要素用于选择最小充分的执行描述，只输出当前镜头真正需要的内容。

## 可执行信号库

### 眼神与注意力

写具体对象和变化路径：

- 视线从对象 A 移到对象 B；
- 听见刺激后，原注视短暂停住，再转向证据；
- 避视后重新落回说话者；
- 眼睛先到目标，头部随后小幅跟随；
- 需要持续凝视时保留自然微眼跳和少量眨眼。

避免“坚定地看着”“眼神充满绝望”等不可验收抽象句。

### 呼吸与发声准备

只在声音、体力或情绪转折确实依赖呼吸时使用：

- 吸气变浅、短暂停住、再缓慢呼出；
- 说话前气口卡住，决定后才开口；
- 奔跑/哭泣/受伤后的句子与真实气息负荷一致；
- 长呼气带来肩部下降，证明紧张退出。

不得给每个情绪机械分配固定呼吸链。

### 嘴唇、下颌与面部

选择能被当前景别看见的少量结果：

- 抬起的下颌松开；
- 正要说话的嘴唇停住并闭合；
- 嘴角短暂上提后被压回；
- 咬肌绷紧后在决定改变时松开；
- 下唇或下巴出现短暂不稳定，但不扩大成全脸用力。

允许“紧张、惊讶、悲伤”等简短标签辅助，但执行重点仍是可观察动作。禁止颜色化人物情绪、自然/物理隐喻和文学比喻。

### 手部、持物与动作中断

- 写明哪只手、物件归属、起点、接触、结果和停止条件；
- 关键选择可用“原本继续的动作停止”或“第二次试探终于完成”证明；
- 交接遵守起因 → 起势 → 接触 → 新归属；
- 手部高风险时减少并发动作，必要时拆镜或插入；
- 结果镜仍要回到正确人物与物件归属。

### 姿态、重心与距离

- 以人物和剧情为准写前倾、后撤、让路、挡住、坐下或重新站稳；
- 距离变化必须有对象、路径、停点和关系意义；
- 地位变化可由谁保持位置、谁停止前进、谁让出通道来证明；
- 不把“高地位少动、低地位碎动”等经验当成固定公式。

### 倾听与多人反应

- 关键接收者对具体刺激产生有限且有因的变化；
- 群体反应可错峰，但只选择有信息职责的人，不要求每个人显著微动；
- 背景状态随事件阶段更新，重大事件后不继续无关庆祝；
- 非说话者闭口，不串嘴；人物看谁不改变声音由谁发出。

## 对白、声音与口型

所有实际发声只用项目主语言。独立音色引用模块不输出，人物自动附带音频不得删除。一个连续镜头≤3秒，长对白跨真实切点连续发声，不重念、不加速；表演变化不能用来伪装切镜。

1. 内部分别登记正常现场/画外对白与旁白；旁白只转对应可见画面，不发声或驱动口型，正常对白声音保留。
2. 现场对白保留原文、发声者、对象和顺序。内部说明可用工作语言，台词保持当前项目的权威语言。
3. 口型只对已授权的人声事件同步；VO不自动驱动现场人物口型。
4. 长句按语义组、行动意图和气口组织，不机械逐词切分。
5. 重音、速度、音量和句尾服务策略变化；不平均重读，不默认喊叫。
6. 气口与动作负荷相容；关键发音时避免遮嘴或急转头。
7. 生成后必须审听，静帧、字幕或无声播放不能证明音轨正确。

## 可直接编译的句法

表演句优先使用：

`正式角色/角色实例 + 当前状态 + 已发生刺激 + 一个主要可见变化 + 保持/停止条件 + 结束证据`

示例仅说明句法，不授权加入具体项目：

> 听完该句，陈越抬起的手停在胸前，没有继续伸向门口；保持陈越近景，直到视线从赵宁移向门。

若动作与摄影有依赖，由 L2 合并成因果句；本文件不另建表演模块或重复同一动作。

## 诊断与修正

先描述可观察问题，再定位根因：

- 反应提前：把刺激和反应重新排序；
- 动作过多：保留承担变化的主要证据，删去装饰微动作；
- 死眼/木偶感：补明确注视对象或由刺激引发的一次注意力变化；
- 口型串人：锁定发声者，非说话者闭口倾听；
- 呼吸与体力矛盾：按动作负荷重写气口；
- 情绪突变：补上一镜余波或本镜触发，不增加无因表情；
- 同人状态混淆：恢复角色实例与完整素材映射，不能只改情绪词。

遵守单变量修正。多个错误只有在确认来自同一根因时联动修改；否则保护已正确的脸、资产、空间、动作和声音。

## 输出检查

- [ ] 当前主要证据由 v3.4 导演判断选定，并与刺激、对象和结束状态一致。
- [ ] 刺激先于反应；开始状态和结束状态可见。
- [ ] 景别能覆盖承担证据的部位。
- [ ] 一个节拍没有堆叠多个无关重大动作。
- [ ] 眼神有具体对象，持物和距离有连续性。
- [ ] 权威对白原文、发声者、类型和顺序未改。
- [ ] 声音权限符合 L0/L1，未把项目特例永久化。
- [ ] 同一角色多状态使用角色实例消歧；剧梦引用仍使用完整素材名。
- [ ] 人物情绪使用可观察动作表达；画质描述和局部限制都与当前镜头直接相关。
- [ ] 诊断后只修改失败变量，接受 take 才更新 Sequence Canon。

# 短剧项目工作入口

通用工作流目录：`{{COMMON_ROOT}}`。

开始工作或恢复任务时，先读取 `项目启动说明.md`、`项目参数.json`、`制作台账.json` 和 `工作流版本锁.json`，然后读取通用目录的 `工作流规则索引.md` 及当前任务所需 Skill。没有文件就标记缺口，不能凭旧聊天编造事实。

`项目参数.json` 保存主语言、旁白画面化、声音依赖、用户/SRT时间来源、5秒连续镜头上限及有作用范围的用户裁决；`制作台账.json` 保存动态任务和验收状态。用户当前明确要求优先，变更记下来源、作用范围和替代关系。

保留六个Skill分工。视频模型工作流第7.3节和剧梦适配负责内容；《资产全名版》第24节负责最终排版；只交一份最终提示词。中文导演说明和资产名不能进入成片。

检查实际加载的工作流文件哈希；与版本锁不同先报告差异，不凭“已读过”跳过变更核对。版本锁是证据，不是压倒当前用户要求的权限。

历史提示词、复盘、抽卡日志和Canon可能记录旧规则；只用于还原，不覆盖最新有效裁决。旧提示词需按当前规则重新编译/检查才能用于新提交，不能直接拿历史稿上线。

每次提交保存实际文本/资产依赖/版本/任务ID和检查记录；未知任务状态先核对，不重复提交。未得到平台与费用授权不得生成；不删除人物自动附带音频，不把未验Take写成已接受。

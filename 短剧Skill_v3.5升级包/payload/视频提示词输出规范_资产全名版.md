# 视频提示词输出规范｜资产全名版

版本：v1.1｜配套工作流v3.5｜2026-09-24

职责：负责最终排版、字段呈现和真实资产完整名表达。视频模型工作流第7.3节及剧梦适配Skill负责内容输出；本文件不另建导演规则、改写剧情或另定时间预算。

# 1. 核心任务
逐集生成详细、可提交的视频提示词。最终只输出一套排版，不再附一套五模块重复稿。每个独立生成段保持足以执行的细节，约2500中文字是详细度参考，不是硬性字数，更不是每个5秒镜头都写2500字。

# 2. 开工前读取
读取当前项目配置、权威剧本、真实资产、最新有效决定、已确认SRT/音轨和连续性来源；六个Skill按各自职责执行。缺口只阻塞真正受影响的范围，不从其他剧借同名资产。

# 3. 权威与职责
用户当前明确要求优先；项目事实与资产、模型实现和导演原则按现有层级裁决。内容完整性由编译器与适配器核对；展示顺序以第24节为准，不能让排版覆盖内容。

# 4. 真实完整资产名
人物、场景、顶视图和重要道具绑定当前项目真实存在且逐字一致的素材。角色身份、角色实例、平台完整名称分别核对，不凭文件名推断实际图像内容。

# 5. 引用格式
使用 `指代对象@真实资产完整名称`。`@` 前保留明确指代；顶部与正文使用相同完整名，不以猜测名称、图1或人物A冒充。

# 6. 正文再次出现资产
时间轴中再次出现人物、重要场景、道具，继续使用完整引用形式，不改成含混简称。资产名是绑定键，不是成片标牌、字幕或发声文本。

# 7. 独立生成段
每段重列实际使用的【人物引用】【场景引用】、适用的【站位图引用】【道具引用】以及【风格】【场景】。不列整部剧的所有资产；缺少某类使用项则省略该引用区。

# 8. 时间预算
采用当前用户要求或已确认SRT的实际区间，不固定单集时长，不固定生成段数。段长由来源、对白、动作、反应、平台实际入口共同确定；生成段可包含多个镜头。

# 9. 镜头时间标签
每个连续镜头使用 `【0.00–4.20s｜镜头1】` 格式；实际时长必须大于0秒且≤5秒。相邻镜头无时间空白或重叠，换镜写明真实剪接。节拍、转焦和新标签不等于切镜；每个独立生成段从镜头1重新编号。

# 10. 正常对白与人物附带音频
正常现场/真实画外对白完整保留原文、顺序、说话人及声音。对白在所属镜头出现一次；长句可跨切点，后镜只注明同一声音事件继续，不重抄完整句子或重新发声。

不输出独立音色/声音/音频引用模块，不新增声音文件@引用。人物引用自动附带的音频不能删除；核对它不等于给最终提示词增加一个声音引用区。

# 11. 旁白
旁白仅转成与原文对应的可见画面；不朗读、不驱动口型，不擅改为现场对白或烧录字幕。内部保留“原旁白信息→对应镜头/证据”映射；这张分析表不提交视频模型。真实画外对白不因名称含“画外”就被当作旁白删除。

# 12. 风格
按当前项目，默认真人实拍电影质感、9:16、硬切为主。机位运动要有动作或叙事原因，不堆赞词，也不因限制镜长而用随机切镜破坏因果。

# 13. 声音和成片语言
无BGM、无无来源铺底、不擅增对白；环境声有实际来源。所有人物发声和可读文字只用本剧主语言，不能在西语剧中出现中文或其他语言。中文导演说明及中文资产文件名仅为内部输入。

# 14. 场景与空间
呈现编译器已确定的开场站位、朝向、视线、出入口、轴线及道具初始归属；不随排版重定义固定场景。

# 15. 每镜内容
按可执行自然语言写明：取景/机位、起点、刺激、主要动作与反应、摄影机响应、对白/环境声、结束状态和切换。实际镜头最长5秒；不要把一镜拆成多个“节拍标签”来规避。

# 16. 表演
使用导演已选择的可见证据，不另造表演模板。刺激先发生，反应后出现；镜头能看清承载变化的部位。

# 17. 多人戏
人物、实例、空间与观看对象明确；不为缩短镜头而打乱左右、提前让第三人出场或无因清空现场。

# 18. 连续性
继承有效起点，保护脸、服装、伤势、持物、朝向、门状态和情绪余波。计划、实际观察与正式接受状态分开；旧错误不自动升级为Canon。

# 19. 特殊世界观
仅按本项目世界观输出，不把某剧灵魂或科技设定变为跨剧默认。画面化旁白同样不能新增现实触碰、复活或其他禁止事件。

# 20. 人物外观
保持权威资产；不在正文重新定义服装款式和颜色。状态变化由当前事实与资产支持，不能把另一人物/时期的外观继承过来。

# 21. 道具
关键交接保留起因、接触和归属结果。长动作可以由多个≤5秒的镜头连贯覆盖，不能省略决定性节点。

# 22. 画面文字
必要的屏幕、界面、标牌、报告、标签直接在视频里生成对应主语言的确切文字，不安排字层后期。编译器先确定文本、来源、承载面、时段和变化；排版只把它放在发生处。

使用 `画面文字〔TXT-01〕：“已核对的主语言原文”`；后续镜头保持同一文本时引用ID说明继续显示，不把工作ID写进成片。不要给模型“某某类短标题”等未定稿指令，也不附中文翻译。准确数字和已确认专名按主语言版本使用。对不需要信息的表面不新增字；这不允许把剧情必要信息留空。

直接生成出现其他语言、乱码或错误词时，标记失败并按已授权范围修正；不能宣称加禁令即可保证通过，也不能自动转后期。主语言验收与是否有中文是两件事，无中文不代表西语正确。

# 23. 末态承接
每段说明下一段真正依赖的末态。跨生成请求不可假定模型有记忆；同段内则避免重复全套固定条件。

# 24. 最终固定模板

以下仅用于装配，真实输出必须填好必要值并删除说明性占位符。没有某类资产使用就省略该引用区；没有对白就注明无人声，不编造台词。

```text
【生成段1｜实际总时长秒】

【人物引用】
正式角色指代@真实人物完整资产名

【场景引用】
场景指代@真实场景完整资产名

【站位图引用】
站位图指代@真实站位图完整资产名

【道具引用】
道具指代@真实道具完整资产名

【风格】
当前画幅、具体摄影/光线、主语言、声音和画面硬约束。

【场景】
当前空间、开场人物状态、视线、轴线和道具归属。

【0.00–4.00s｜镜头1】
景别、机位、起始状态；刺激、动作和必要反应；摄影机响应。
现场/画外对白〔D01〕：正式发声者、原文、发生时点；允许一次发声跨到下一镜。
画面文字〔TXT-01〕：“已核对的主语言原文”；指定承载面和出现时点。
有来源环境声；末态；4.00秒硬切下一镜。

【4.00–8.00s｜镜头2】
承接状态；新的实际取景与主要变化。
对白〔D01〕沿前镜连续到结束位置，不重复原句、不重新发声。
画面文字〔TXT-01〕维持在原承载面，不生成额外文本。
必要环境声变化、末态与切换。

【末态承接】
下一段依赖的必要结果；尚未在前文表达的少量局部稳定性要求。
```

模板中的4秒和8秒只是排版示例，不能复制为固定时长；总时长取真实来源，每镜≤5秒。

# 25. 详细度
保留对动作、机位、表演、视线、声音、资产与连续性真正有用的细节。不机械凑2500字，不把长生成段误当成长镜头。

# 26. 输出前检查
内容正确、主语言唯一、旁白画面信息完整、正常对白原文不变、人物附带音频保留、无独立声音引用、画面文字直接生成、单镜≤5秒、时间轴连续、真实资产全名一致、末态可接。内部清单不属于平台提示词；实际成片必须另验。

# 27. 交付
按指定范围每集独立Markdown，必要时打包ZIP；保存实际提交稿与源稿差异。只读、本地就绪、绑定完成、已提交、出片、待验和最终接受是不同状态，不混用。
